## 📌 Overview

A web player interface clone of **Spotify**. Faithfully replicates Spotify’s iconic dark theme, sidebar navigation, featured playlists gallery, and persistent bottom media player bar.

---

## ✨ Key Features

- **Bottom Media Player:** Complete audio playback controls including Play/Pause, Skip, Previous, Seek bar, and Volume slider.
- **Spotify Sidebar Navigation:** Home, Search, Your Library, and Create Playlist navigation sections.
- **Dynamic Song Cards:** Album art cards with hover play button transitions.
- **Responsive Grid Layout:** Adapts seamlessly between desktop wide screen and compact mobile viewports.

---

## 💻 Tech Stack & Architecture

- **Frontend Core:** HTML5 Audio API, CSS3 Custom Properties & Flexbox, JavaScript Audio Controller
